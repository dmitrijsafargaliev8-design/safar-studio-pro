# SAFAR STUDIO PRO v5.0

Открой `public/console.html` для автономного прослушивания. Нажми **Слушать**, попробуй Solo/Mute, выдели такты на волне и переключи A/B. Демо «Ночная смена» содержит программно синтезированные инструменты и синтезированную речевую партию. Текст и звук входят в файл.

Для облачного запуска открой **LAUNCH_IN_5_MIN.md**. В корне находятся Next.js-проект для Vercel, миграция Supabase и автономный ноутбук Colab. Сервисных секретов в браузерной сборке нет.

| Каталог | Содержимое |
|---|---|
| `app/`, `lib/` | Next.js 15, TypeScript, Tailwind, аккаунты, экономика, checkout, webhooks и сертификаты |
| `console/`, `public/` | Звуковой движок браузера, DAW, шрифты, автономный HTML и клиентский Blind A/B |
| `engine/`, `safar_modal_server.py` | Генерация, LoRA, сепараторы, мастеринг, проверка дикции и сохраняемые задачи |
| `supabase/` | Транзакционная миграция, кредитный журнал, роли и учёт продаж |
| `tests/`, `scripts/` | Локальные проверки, сборка HTML и ноутбука, настройка Stripe |
| `VERIFICATION.md` | Результаты прогонов и границы локальной проверки |
| `API.md`, `MODELS_AND_RIGHTS.md` | Контракты, лицензии, особенности моделей и аудиоэкспорта |

Для воспроизводимой сборки используй `npm ci` и `npm run build`. После редактирования интерфейса выполни `python scripts/build_console.py`. После изменения GPU-движка выполни `python scripts/build_notebook.py`. Исходник v4.1 использован для сохранения старых API-контрактов. Новый деплой имеет собственное имя и тома.
