## Повторить проверки

```sh
npm ci
npm run check
npm run build
npm run test:ledger
npm run test:billing
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v
```

Для браузерной проверки установи Playwright и Chromium, а также FFmpeg с ffprobe. Затем выполни `python tests/browser_smoke.py`. Путь к уже установленному браузеру можно передать через `CHROME_BIN`. Скрипт сам создаёт два коротких файла импорта и проверяет скачанные ZIP и вертикальное видео. Сырьё теста создаётся во временном каталоге.
